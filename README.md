# 🐶 Dogs

Plataforma social para compartilhar fotos de cachorros, desenvolvida com React.

> ⚠️ Projeto em desenvolvimento

## 🚀 Tecnologias

- React
- React Router DOM
- Vite
- WordPress REST API

## ⚙️ Como rodar o projeto

```bash
# Instalar dependências
npm install

# Rodar em desenvolvimento
npm run dev
```

## 🔗 API

O projeto consome a [WordPress REST API Dogs](https://www.origamid.com/curso/wordpress-rest-api-dogs).

Endpoint: `https://dogsapi.origamid.dev/json/`
